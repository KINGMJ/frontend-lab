# 002 操作符

对应官方文档：[Operators](https://dart.dev/language/operators)。

算术、比较、逻辑和三元运算符的样子与 JavaScript 接近。下面这些规则不同，写的时候要单独记。

## 和 JavaScript 不一样的地方

**`if`、`&&`、`||`、`!` 只接受 `bool`。** 条件必须是 `true` 或 `false`。字符串、数字、列表没有真假值，`if (name)`、`if (count)` 不能编译。空字符串和 `0` 也不会被当成假。

`&&` 和 `||` 的结果也是 `bool`，不会把操作数本身交出来。JavaScript 里常用的 `value || defaultValue` 在这里不成立。值为空时用 `??`：

```dart
String playerName(String? name) => name ?? 'Guest';
```

`??` 只判断 `null`。Dart 没有 `undefined`。

**`/` 得到小数，`~/` 才得到整数。** `5 / 2` 是 `2.5`（`double`）。截断成整数用 `~/`：`5 ~/ 2` 是 `2`。余数仍是 `%`。

**`+` 不把数字和字符串自动拼在一起。** `'5' + 2` 是类型错误。字符串插值写成 `'5/2 = ${5 ~/ 2}'`。

**`==` 表示值相等，没有 `===`，也不做类型转换。** `"1" == 1` 不能通过类型检查。两个都是 `null` 时 `==` 为真，只有一边是 `null` 时为假。要判断是不是同一个对象，用 `identical(a, b)`。

**类型判断用 `is`、`is!` 和 `as`。** `is` 在条件成立的分支里收窄类型。`as` 是运行时转换，类型不对就抛错。TypeScript 的 `as` 只存在于编译期，运行时不会检查。

```dart
if (employee is Person) {
  employee.firstName = 'Bob';
}
```

**后缀 `!` 是空断言。** `foo!.bar` 表示你断定 `foo` 不是 `null`。它若是 `null`，运行时抛错。前缀 `!` 才是布尔取反，而且只能用在 `bool` 上。`?.` 和 `?[]` 与 JavaScript 的可选链对应：左边是 `null` 时，整个表达式是 `null`。

**级联 `..` 在 JavaScript 里没有对应写法。** 它在同一个对象上连续调用成员，整个表达式的值仍是这个对象：

```dart
var paint = Paint()
  ..color = Colors.black
  ..strokeWidth = 5.0;
```

对象可能是 `null` 时，第一段写成 `?..`。`..` 不能接在返回 `void` 的调用后面，因为后面没有对象可以继续用。

**`...` 只出现在集合字面量里。** 它可以把另一个列表或集合展开进去。可能是 `null` 时用 `...?`，为 `null` 就跳过。不能像 JavaScript 那样在函数调用里写 `f(...args)`。

**许多操作符是左侧对象的方法。** `a + b` 调用的是 `a` 的 `+`。类可以定义自己的 `+`、`==`、`[]`。JavaScript 没有运算符重载。

Dart 没有乘方运算符 `**`，乘方用 `dart:math` 里的 `pow`。

## 算术

| 操作符 | 含义 |
| --- | --- |
| `+` `-` `*` | 加、减、乘 |
| `-expr` | 取相反数 |
| `/` | 除，结果是 `double` |
| `~/` | 整除，结果是 `int` |
| `%` | 余数 |

`++` 和 `--` 分前后。`++a` 先加再把新值交出来，`a++` 先把旧值交出来再加。

## 相等和关系

`==`、`!=`、`>`、`<`、`>=`、`<=` 的比较方向与常见语言相同。`==` 的过程是：有一边是 `null` 时，两边都是 `null` 才为真；否则调用左边对象的 `==` 方法。

## 类型测试

| 操作符 | 含义 |
| --- | --- |
| `is` | 运行时是不是这个类型 |
| `is!` | 运行时是不是不属于这个类型 |
| `as` | 转换成这个类型，失败则抛错 |

`obj is Object?` 永远为真。不确定类型时用 `is`，确定时才用 `as`。`employee as Person` 在 `employee` 是 `null` 或不是 `Person` 时抛错；`if (employee is Person)` 在那种情况下只是不进入分支。

## 赋值

`=` 直接赋值。`??=` 只在左边目前是 `null` 时赋值。复合赋值 `+=`、`-=`、`*=`、`/=`、`~/=`、`%=` 等等价于先运算再赋回，例如 `a *= 3` 就是 `a = a * 3`。

## 逻辑

| 操作符 | 含义 |
| --- | --- |
| `!expr` | 把 `bool` 取反 |
| `&&` | 并且，左边为假就不再算右边 |
| `\|\|` | 或者，左边为真就不再算右边 |

## 位运算

`&`、`|`、`^`、`~`、`<<`、`>>`、`>>>` 通常用在整数上。`>>>` 是无符号右移，语言版本至少 2.14。大整数和负数的位运算在原生平台和 Web 上可能不同：Web 上这些运算会先收成 32 位。

## 条件表达式

`condition ? expr1 : expr2` 的条件必须是 `bool`。`expr1 ?? expr2` 在 `expr1` 不是 `null` 时取它，否则计算并返回 `expr2`。

## 级联

`..` 让连续的成员操作都作用在同一个对象上，表达式的值是这个对象，而不是最后一次调用的返回值。可能为 `null` 时，第一段用 `?..`。官方说明里，双点是语法的一部分，并不算一个真正的操作符。

## 展开

`...` 和 `...?` 属于集合字面量，不是可以单独使用的运算表达式。因此 `[...a + b]` 这样写是合法的：先算 `a + b`，再展开。细节在后面的集合一章。

## 其余

| 操作符 | 含义 |
| --- | --- |
| `()` | 调用函数 |
| `[]` | 按下标读取，例如 `list[1]` |
| `?[]` | 左边是 `null` 时结果为 `null`，否则按下标读取 |
| `.` | 读取成员 |
| `?.` | 左边是 `null` 时结果为 `null`，否则读取成员 |
| `!` | 断言不是 `null`，失败则抛错 |
